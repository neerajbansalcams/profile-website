⌘ How to Access Skills
Skill Tool (Claude Code)

In Claude Code CLI, use the Skill tool with the skill name. Claude invokes it automatically when a task matches — or you can trigger it by typing the slash command.

Slash Commands

Type a slash command like /brainstorm or /code-review directly in your message. Only invoke commands listed in the system as available skills.

Auto-Triggered

Some skills fire automatically at conversation start (using-superpowers), before plan mode, or on hook events. No user action required.

Plugin System

Skills are distributed via plugins: superpowers, frontend-design, gstack, claude-mem, security-guidance. Install via the plugin system in Claude Code settings.
